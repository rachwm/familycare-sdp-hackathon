# FamilyCare data

This directory contains prototype datasets and generated development artifacts.

## Included data

- `fall/fall_features.csv`: extracted features used by the fall-detection experiments.
- Utility-model inputs are prepared under `data/utility/` when the optional ingestion and feature-engineering workflow is run.
- `data/runtime/` is generated by the running prototype and is intentionally ignored by Git.

## Data boundaries

The repository must not contain real resident names, contact details, medical records, addresses, access credentials, or production sensor feeds. Demonstration residents and events are fictional or simulated.

The fall-model evidence is based on 102 recorded samples from three participants. See [the evaluation report](../documentation/fall-model-evaluation.md) for the method, limitations, and judge-safe wording.

## Reproducibility

Model-training and evaluation code lives in:

- [`fall_detection/`](../fall_detection/)
- [`utility_anomaly/`](../utility_anomaly/)

Generated runtime incident data may disappear when the hosted demo restarts. This is expected for the hackathon deployment and must not be described as durable production storage.
